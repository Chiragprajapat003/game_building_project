# 🎮 JavaScript Mini Games Collection

A collection of simple and interactive **mini games** built using **HTML, CSS, and JavaScript**.  
This project focuses on improving logic building, DOM manipulation, and user interaction.

---

## 📖 Overview

This repository contains multiple mini games designed to practice core JavaScript concepts such as event handling, state management, and dynamic UI updates.

Each game is lightweight, browser-based, and built without external libraries to strengthen fundamental development skills.

---

## 🎯 Games Included

### 🎨 Guess The Color
- Generate and guess the correct color
- Improves understanding of RGB values and DOM updates

### 🧠 Memory Flip Card Game
- Flip cards and match pairs
- Enhances logic building and state tracking

### 📝 Todo Game
- Add, delete, and manage tasks
- Demonstrates CRUD operations using JavaScript

### 🎲 Mini Games Hub
- Central place to access all games
- Simple navigation between games

---

## ✨ Features

- 🎮 Multiple interactive games
